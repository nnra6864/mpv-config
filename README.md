A minimal, convenience first, quality oriented mpv config.

## Keymap

| Key       | Action           | Description                              |
|-----------|------------------|------------------------------------------|
| t         | Tachytome        | Open the Tachytome menu.                 |
| f         | Fullscreen       | Fullscreen mpv.                          |
| r         | Rotate           | Rotate the content.                      |
| b         | Toggle Banding   | Toggle Banding.                          |
| C         | Auto Crop        | Zoom in to remove horizontal black bars. |
| Ctrl+d    | Auto Deinterlace | Deinterlace the video.                   |
| Ctrl+c    | Copy Path        | Copy the file path.                      |
| Shift+DEL | Trash File       | Trash the file.                          |
| DEL       | Toggle OSC       | Toggle OSC.                              |
| Ctrl+r    | Reload Subtitles | Reload Subtitles.                        |


### Navigation

| Key                   | Action    | Description        |
|-----------------------|-----------|--------------------|
| g-t                   | Go To     | Tachytome Go To.   |
| RIGHT/LEFT            | Seek +-5  | Seek +-5 seconds.  |
| Alt+RIGHT/LEFT        | Seek +-1  | Seek +-1 seconds.  |
| Ctrl+RIGHT/LEFT       | Seek +-60 | Seek +-10 seconds. |
| Ctrl+Shift+RIGHT/LEFT | Seek +-60 | Seek +-10 seconds. |

### Volume

| Key           | Action      | Description            |
|---------------|-------------|------------------------|
| UP/DOWN       | Volume +-10 | Change Volume by +-10. |
| Shift+UP/DOWN | Volume +-5  | Change Volume by +-5.  |

### Zoom

| Key         | Action        | Description      |
|-------------|---------------|------------------|
| Alt++/-     | Zoom +/-0.1   | Zoom by +/-0.1.  |
| Alt+i/o     | Zoom +/-0.01  | Zoom by +/-0.01. |
| MWHEEL_UP   | Zoom +0.1     | Zoom by +0.1.    |
| MWHEEL_DOWN | Zoom -0.1     | Zoom by -0.1.    |
